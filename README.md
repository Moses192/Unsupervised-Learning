# Unsupervised-Learning
This project uses the K-Means clustering algorithm to segment mall customers based on Annual Income and Spending Score. It demonstrates unsupervised machine learning by identifying customer groups without predefined labels.
## Procedures
1.Import the required libraries.
2.Load the Mall Customers dataset.
3.Explore and inspect the dataset.
4.Select Annual Income and Spending Score as clustering features.
5.Use the Elbow Method to determine the optimal number of clusters.
6.Train the K-Means clustering model.
7.Assign each customer to a cluster.
8.Visualize the clusters and their centroids using a scatter plot.
9.Interpret each customer segment based on spending behavior and income.
10.Recommend business or marketing strategies for each customer segment.
